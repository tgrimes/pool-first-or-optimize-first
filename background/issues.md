# Issues found by the background report

Written 2026-10-29 by stage 4 on the first draft (commit 375b006, quick-run numbers). Severity: blocking (a claim does not hold), substantive (a claim needs a changed statement, a code fix, or a new source), editorial. No issue is blocking. Each is shown in `background/background.html` where the last column says.

Corrected the same day, in stage 3's revision round 1: the first version of C1 said the simulation was not affected because its markers are continuous. It was. Under predictive mean matching, which imputes observed values, and for complete cases, adjacent grid points with no observed value between them tie in the same way. The C1 row now says so; the fix was applied and the quick run and the application were run again.
