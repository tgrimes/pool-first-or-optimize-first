The code is organized as a research compendium [@marwick2018]: an R package whose functions are documented and tested, analysis scripts that call those functions and write every result to a results folder, and this manuscript, which reads only from that folder, so that every number, table, and figure in it is computed from the saved results when the document is rendered. Each simulation cell has its own random seed, derived from the design table, and the per-replicate results are saved rather than summaries. The software and package versions used are recorded with the results.
